Overview

Rich, Responsive User Interfaces with SAP UI5 & Fiori

We leverage SAP UI5 to enhance the user experience. SAP UI5 helps to create apps with rich user interfaces for web business applications. By leveraging the power of SAP Fiori, most SAP functions — such as workflow approvals, information lookups, and self-service tasks — can be addressed.

Fiori offers a set of design principles and a design concept. SAP UI5 is a dynamic technology that offers a robust library framework. A custom UI5 app can be built without SAP Fiori design guidelines; however, those applications that adhere to Fiori design guidelines are called Fiori applications, and those that don't are called custom UI5 apps. UI5 can be seen as the progenitor of all Fiori apps.
